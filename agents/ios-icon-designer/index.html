How it works

The workflow

1
Install once — copy ios-icon-designer.md into ~/.claude/agents/. Restart your Claude Code session.
2
Brief the agent — “use the ios-icon-designer agent to design an icon for my app X, which is a Y for Z”. Optionally name palettes to avoid (e.g. you already have a purple chat app).
3
It picks the metaphor — and writes the prompt, runs gpt-image-2, downloads the PNG, packages it into your AppIcon.appiconset, and runs the squint test.
4
You review — agent won't auto-commit. Approve, regenerate with a tweak, or pivot to another concept.
