What's in the bundle

Everything you need to ship icons that match.

  • The agent file — ios-icon-designer.md, 13 KB markdown. Drop into ~/.claude/agents/ and Claude registers it on next session.
  • House style spec — background palettes, subject form, accent rules, safe-area guidelines. Codified from a curated reference grid of well-designed iOS icons.
  • Vetted gpt-image-2 prompt template — with the full-bleed canvas rule (so the model doesn't draw an inner squircle frame) and the hard NO text/letters/numbers guardrail (so it doesn't stamp app names).
  • The single-1024-PNG xcassets recipe — modern AppIcon.appiconset packaging, no hand-generating 12 sizes.
  • 60-pixel squint test — encoded verification step so you don't ship an icon that mushes at Spotlight size.
  • Worked examples from three real shipped apps (Pulse, Aside, Skyline) — exact prompt seeds to adapt.
  • 20 sample icons at 1024×1024 — full-res versions of every icon above, ready to study or use as palette reference.
  • PDF contact sheet — single page of all 20 samples for sharing with clients or teammates.
  • 30-second install README — walks through setup.

How it works

The workflow

1
Install once — copy ios-icon-designer.md into ~/.claude/agents/. Restart your Claude Code session.
2
Brief the agent — “use the ios-icon-designer agent to design an icon for my app X, which is a Y for Z”. Optionally name palettes to avoid (e.g. “not purple, my chat app already uses purple”).
3
It picks the metaphor — and writes the prompt, runs gpt-image-2, downloads the PNG, packages it into your AppIcon.appiconset, and runs the squint test.
4
You review — the agent won't auto-commit. Approve, regenerate with a tweak, or pivot to another concept.

·
